# Filesystem

![pub package](https://img.shields.io/npm/v/@agent-smith/feat-fs)

Manage files and directories with a language model

## Install

```bash
npm i -g @agent-smith/feat-fs
```

Add the plugin to your `config.yml` file and run the `conf` command to update the cli.

```yml
plugins:
  - "@agent-smith/feat-fs"
```

```bash
lm conf
```

## Actions and tools

### Directory operations

Available directory tools:

- <kbd>lsdir</kbd> list files and folders names in a directory
- <kbd>dirfiles</kbd> read files in a directory: returns the content of all the files in a given directory, excluding hidden files

### File operations

Available file tools:

- <kbd>readfile</kbd> read a file's content
- <kbd>writetofile</kbd> write to a file
- <kbd>edit-search-replace</kbd> search and replace strings in a file for fast edit

## Agents

Available agents with filesystem tools:

- <kbd>fs-workspace-agent</kbd> a lightweight read, write and explore agent:
    - `lsdir` — list files and folders in a directory
    - `dirfiles` — read all files content in a directory
    - `readfile` — read a file's content
    - `writetofile` — write content to a file
    - `edit-search-replace` — search and replace strings in a file

## Example filesystem agent

```yaml
description: A filesystem agent
model: qwen4b
toolsList:
  - fs-workspace-agent # this tool is a subagent
```
