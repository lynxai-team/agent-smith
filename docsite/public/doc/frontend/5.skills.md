# Skills

Skills are reusable markdown documents that provide context, instructions, or guidelines to agents at runtime. They allow you to inject domain knowledge, coding standards, or procedural instructions into an agent's conversation without modifying the agent's core configuration.

## Overview

Skills are stored in the `skills/` subdirectory within your features folder. Each skill is a subdirectory containing a `SKILL.md` file with YAML front-matter metadata.

When an agent runs, skills can be automatically loaded into the prompt using the `%skill-name` placeholder syntax, or referenced directly in agent definitions.

## Directory Structure

Skills are organized in your features folder:

```
features/
└── skills/
    ├── coding-guidelines/
    │   └── SKILL.md
    ├── documentation-standards/
    │   └── SKILL.md
    └── my-custom-skill/
        └── SKILL.md
```

The `load-skill` tool is available. Example agent with skills:

```yaml
skills:
  - my-skill
prompt: |
  You are a documentation agent.
  
  Available skills:
  {skills}
  
  Task: {prompt}
```

Run `lm update` after creating a skill or registering it for an agent

The skills placeholder will be replaced by the skills names and descriptions

## Load skills in prompt

In the frontend you can load a skill directly in the prompt using this syntax:

```
Execute the following instructions:
%my-skill
```

The `%my-skill` placeholder will be replaced by the content of the skill

## Task Skills

Tasks are managed through a dedicated set of skills. Use `%use-tasks` to load the full task reference guide. See the [Tasks documentation](/frontend/tasks) for details on creating and executing tasks.
