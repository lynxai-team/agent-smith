# Architecture Overview

Agent Smith is a local-first AI agent framework built as a TypeScript monorepo. It enables agents to **think** (LLM inference), **work** (tool calling), **remember** (semantic + transient memory), and **interact** (CLI, WebSocket, server). The entire configuration runtime — backends, features, settings, workspaces — is driven by SQLite with zero hardcoded defaults.

## Four Core Capabilities

### Think — LLM Inference

The inference engine uses an OpenAI-compatible HTTP client (`Lm` class from `@agent-smith/agent`) to communicate with any backend supporting the OpenAI API format. It supports streaming token output, thinking/reasoning tokens, and configurable sampling parameters (temperature, top_k, top_p, min_p, max_tokens). Backends are registered in the SQLite `backend` table and can be of type `browser` or `openai`.

### Work — Tool Calling

All callable units — agents, actions, workflows, commands, and adaptaters — are unified under a single `ToolSpec` interface. The agent runs a recursive tool-calling loop: it sends the prompt to the LLM, receives tool call requests, executes them via the execution engine in `@agent-smith/core`, feeds results back, and repeats until the LLM produces a final text response.

### Remember — Memory Systems

Agent Smith provides two memory backends:
- **Semantic memory** (`@agent-smith/smem`): Uses LanceDB with Xenova embeddings (384d vectors) for persistent vector search across documents.
- **Transient memory** (`@agent-smith/tmem`): A key-value store wrapping browser IndexedDB via localForage, used for short-lived session state.

### Interact — I/O Layer

Three interaction modes are available:
- **CLI**: Terminal-based REPL using Commander.js, accessible via the `lm` command from `@agent-smith/cli`.
- **WebSocket client** (`@agent-smith/wscli`): Reconnecting WebSocket client for real-time server communication.
- **Server** (`server`): Koa-based backend exposing REST API routes under `/api/*` and a streaming WebSocket endpoint at `/ws`.

## Monorepo Structure

Agent Smith consists of 8 packages:

| Package | Role |
|---------|------|
| `@agent-smith/types` | Shared interfaces — all type definitions for agents, tools, callbacks, inference, and WebSocket protocol (leaf package) |
| `@agent-smith/core` | Runtime engine — SQLite DB initialization, config management, feature discovery, tool execution, MCP client |
| `@agent-smith/agent` | Agent class with the recursive inference loop, history management, and `Lm` HTTP client |
| `@agent-smith/smem` | Semantic memory factory (`useSmem`) using LanceDB + Xenova embeddings |
| `@agent-smith/tmem` | Transient memory factory (`useTmem`) wrapping localForage for browser IndexedDB |
| `@agent-smith/cli` | Terminal REPL client — Commander.js commands for agent execution, config management, and feature updates |
| `@agent-smith/wscli` | WebSocket client with auto-reconnect for real-time server communication |
| `server` | Koa backend — REST API (`/api/*`) and WebSocket (`/ws`) for remote agent execution |
