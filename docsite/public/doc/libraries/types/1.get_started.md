# @agent-smith/types

Shared interfaces for the entire Agent Smith framework. This package defines all data shapes, callback signatures, and protocol types used across every other package — from agent inference to tool execution, WebSocket communication, and memory management.

## Overview

`@agent-smith/types` is a **leaf package** with no runtime dependencies beyond TypeScript. It exports type definitions organized into these categories:

### Agent Types
- <code>AgentParams</code> — constructor parameters for the <code>Agent</code> class
- <code>AgentSpec</code> — YAML agent definition structure (name, prompt, model, tools, etc.)
- <code>AgentSettings</code> — per-agent inference configuration (model, temperature, backend)
- <code>AgentState</code> — reactive state management for agents

### Tool Types
- <code>ToolSpec</code> — unified tool definition with name, description, arguments, and execute function
- <code>ToolCallSpec</code> — active tool call specification (id, name, arguments)
- <code>ToolTurn</code> — a tool call paired with its response in a conversation turn

### Inference Types
- <code>InferenceParams</code> — sampling parameters (temperature, top_k, top_p, max_tokens, etc.)
- <code>InferenceOptions</code> — inference request options (tools, history, system message)
- <code>InferenceResult</code> — result returned after inference (text, stats, tool calls)
- <code>LmProvider</code> — language model provider interface with infer/loadModel/abort methods

### History Types
- <code>HistoryTurn</code> — a single conversation turn (user message, assistant response, tools, images)
- <code>ToolTurn</code> — tool call and its response within a turn

### Model Types
- <code>ModelInfo</code> — model metadata (id, status, context window size, vision support)
- <code>ModelStatus</code> — union type for model lifecycle states (unloaded, loading, loaded, failed)

### WebSocket Protocol Types
- <code>WsClientMsg</code> — client-to-server message structure
- <code>WsServerMsgType</code> — 20+ server-to-client message types (token, thinking, tool calls, etc.)
- <code>StreamedMessage</code> — real-time streamed update structure
- <code>ServerParams</code> — WebSocket client connection parameters

### Configuration Types
- <code>ConfigFile</code> — application configuration structure (features, backends, agents)
- <code>InferenceBackend</code> — backend definition (type, URL, API key)

### Core Feature Types
- <code>FeatureSpec</code> — discovered feature metadata (agent, action, workflow, skill, etc.)
- <code>FeatureType</code> — union of all feature kinds
- <code>WorkflowStep</code> — step in a workflow pipeline

### Callback Interfaces
- <code>InferenceCallbacks</code> — inference event callbacks (onToken, onError, onEndEmit)
- <code>AgentCallbacks</code> — agent interaction callbacks (onToolCall, onTurnEnd, onAssistant)
- <code>AllCallbacks</code> — combined inference + agent callbacks

### Utility Types
- <code>VerbosityOptions</code> — fine-grained debug output control
- <code>PromptProcessingProgress</code> — prompt processing statistics
- <code>InferenceStats</code> — full inference performance metrics
- <code>Workspace</code> — workspace definition (name, path, properties)

## Installation

This package is a dependency of all other Agent Smith packages. Install it directly or rely on transitive installation:

```bash
npm install @agent-smith/types
```

Or reference it in your monorepo workspace dependencies:

```json
{
  "dependencies": {
    "@agent-smith/types": "workspace:*"
  }
}
```

## Usage

All types are imported from the package root:

```typescript
import type { AgentSpec, ToolSpec, InferenceParams, HistoryTurn } from "@agent-smith/types";

const agent: AgentSpec = {
  name: "assistant",
  prompt: "You are a helpful assistant.",
  model: "llama3",
  description: "General purpose assistant"
};

const tool: ToolSpec = {
  name: "calculator",
  description: "Performs arithmetic calculations",
  arguments: {},
  type: "agent",
  parallelCalls: false,
  execute: async (args) => 42
};
```
