# Server

A Koa-based server that exposes the Agent Smith runtime via REST API (`/api/*`) and WebSocket (`/ws`), enabling remote agent execution with real-time token streaming.

## Install

```bash
cd server
npm install
npm run build
```

The build step compiles TypeScript sources to `dist/`. The package is published as `@agent-smith/server`.

## Run

After building, start the server:

```bash
npm run server
```

Or in development mode with hot-reload via `ts-node`:

```bash
npm run devserver
```

The server listens on port **5184** by default. Open `http://localhost:5184` in a browser to verify it is running (a `/ping` endpoint returns `{ ok: true }`).

## Configuration

The server uses the Agent Smith SQLite database for all configuration — backends, agents, workflows, tools, settings, and workspaces are stored in 17 tables managed by `@agent-smith/core`. No separate config file is required for basic operation.

Environment variable `NODE_ENV` controls static file serving: when set to anything other than `"development"`, the server serves files from the project root directory.

## Basic Usage

Once running, interact with the server via:

- **REST API** at `/api/*` — query agents, workflows, backends, models, settings
- **WebSocket** at `/ws` — execute agents or workflows with real-time streaming tokens

See the <a href="javascript:openLink('/server/api')">API reference</a> for complete endpoint documentation.
